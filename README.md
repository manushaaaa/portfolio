
#  Числовая угадайка

Консольная игра на Python, в которой компьютер загадывает число от 1 до N, а игрок пытается его угадать.

##  Как играть

1. Запустите файл `ugadyaka.py`
2. Введите максимальное число (до которого будет загадано число)
3. Вводите свои варианты чисел
4. Программа даёт подсказки: "Больше" или "Меньше"
5. Когда угадаете — игра поздравит вас и предложит сыграть ещё

##  Технологии

- Python 3
- Только встроенные библиотеки (ничего дополнительно устанавливать не нужно)

##  Структура

- `ugadyaka.py` — основной файл с игрой
